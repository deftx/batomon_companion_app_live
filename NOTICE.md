## Game assets

`sprites/` contains monster, item, trinket, trainer and event artwork from **Batomon Showdown**, sourced via [batodex.com](https://batodex.com). These assets are the property of **berrymint** and are bundled here solely so the companion can display the units you are playing with, offline.

All rights to Batomon Showdown — its artwork, names, characters and design — belong to berrymint.

**If berrymint would like these assets removed or handled differently, open an issue on this repository and it will be done immediately.**

Please support the developers: [Batomon Showdown on Steam](https://store.steampowered.com/app/4557380/Batomon_Showdown/).

## Data

Win rates, monster statistics and the game database are derived from public data published by [batodex.com](https://batodex.com), used here for informational and analytical purposes.
